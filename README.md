# האנגר (HANGAR) — פרוטוטייפ מקומי

פרויקט Vite + React מינימלי שמריץ את מערכת האנגר באתר מקומי אמיתי,
עם live reload (כמו Live Server), כתובת מקומית ב-Chrome.

## הרצה (צריך Node.js מותקן — גרסה 18 ומעלה)

```bash
npm install
npm run dev
```

הטרמינל יראה כתובת כמו `http://localhost:5173` — פותחים אותה בכרום.
כל שינוי בקוד ישתקף בדפדפן מיידית, בלי לרענן ידנית.

## מבנה

- `src/App.jsx` — מעטפת האפליקציה: ניווט עליון, מתג ערכת נושא, ומתג תפקיד (DEV בלבד — בפרודקשן התפקיד מגיע מה-SSO)
- `src/theme.js` — טוקנים משותפים לערכת בהיר/כהה + מחלקות CSS גלובליות
- `src/roles.js` — מקור אמת יחיד לתפקידים המבניים במערכת
- `src/opsData.js` — קטלוג ודרישות מדומים, משותפים בין הקטלוג ומערכת הטיקטים
- `src/Catalog.jsx` — קטלוג אמל״ח (למשתמשי יחידה בלבד)
- `src/ProductDossier.jsx` — תעודת זהות מלאה לפריט קטלוג, להצגה בפורום
- `src/Tickets.jsx` — מערכת דרישות/טיקטים, מסתגלת לפי תפקיד
- `src/PermissionsDashboard.jsx` — ניהול הרשאות + תצוגת עץ ארגוני
- `src/BrigadeSetupWizard.jsx` — אשף התקנת חטיבה
- `src/DevDashboard.jsx` — דשבורד פיתוח ותשתית (DEV בלבד)

## עצירה

`Ctrl+C` בטרמינל.
